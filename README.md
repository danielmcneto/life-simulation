# Zezzits

A e ecosystem simulator with silly little creatures 

## Table of Contents

- [Features](#features)
- [Contributing](#contributing)
- [Try](#try-it)

## Features

- Genetic mutation 
- Genetic passed away 
- Control over the simulation 

## Controls

- R to reset the simulation 
- 1 to 5 to select a amount of zezzits to spawn
- Q to slow down the game
- W to reset the game's velocity
- Q to speed up the game

### Tech Stack

- **GDscript**
- **LibreSprite**
